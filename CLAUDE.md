# Writing style for this site

- Never use em dashes (—) anywhere: not in UI copy, content data, code comments, or commit messages. Use periods, commas, or colons instead.
- Any new or edited prose that appears on the site (bios, project descriptions, UI copy, meta descriptions) must be run through the `asd-ste100` skill before finalizing: active voice, simple tense, one idea per sentence, no ellipsis of necessary facts, short sentences. Resume-style bullet fragments (dropped leading "I") are fine and don't need an explicit subject added.
